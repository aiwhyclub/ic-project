## 슬라이드 4: 3장 · 이천 방문의 문제

### 그 사람이 이천에서 겪을 문제를 쓰세요

> 공식: [고객]은 [하고 싶은 것]이 있지만, [장벽] 때문에 [불편·포기]를 경험한다.

#### 핵심 문제 1개 (공식으로 작성)

개인화된 여행을 원하는 이천 방문자는 자신의 취향과 일정에 맞는 하루를 구성하고 싶지만, 관광지·체험·카페·맛집 등의 정보가 분산되어 있고 장소 간 연결 정보가 부족해 무엇을 선택하고 어떤 순서로 이동할지 결정하는 데 어려움을 경험한다.

#### 세부 문제 2~3개

1. 세부 문제 1 : 정보 탐색 피로 => 여러 플랫폼을 반복적으로 검색해야 한다.
2. 세부 문제 2 : 상황에 맞지 않는 추천 => 추천은 많지만 ‘나에게 맞는 추천’인지 판단하기 어렵다.
3. 세부 문제 3 : 장소 간 경험 연결 부족 => 좋은 장소를 발견해도 ‘그 다음 어디로 갈 것인가’를 다시 검색해야 한다.

> 3장 · 이천 방문의 문제 (확정이 아니라 현장에서 확인할 가설)

## 슬라이드 6: 5장 · 답사 코스 · 검증계획

### 방문할 3~5곳과 확인할 내용을 쓰세요

| 방문지 | 방문 이유 | 확인할 내용 (가설) |
| --- | --- | --- |
| 이천역 | 대중교통으로 방문하는 타깃의 여행 시작점을 관찰 | 가설: 방문자는 이천에 도착한 이후에도 지도·블로그 등을 다시 검색하며 당일 동선을 조정한다.<br><br>“오늘 어디를 갈 예정인가?”, “코스는 언제 정했는가?”, “어떤 정보를 다시 찾고 있는가?” 확인 |
| 설봉공원 | 대표적인 관광·산책 공간에서 실제 방문객을 만나기 쉬움 | 가설: 첫 장소를 방문한 이후 다음 장소를 정하는 과정에서 다시 검색하는 불편이 발생한다.<br><br>“다음 목적지가 정해져 있는가?”, “어떻게 선택했는가?”, “이 주변에서 갈 곳을 알고 있는가?” 확인 |
| 관고전통시장 | 관광 경험이 실제 로컬 음식·상권으로 이어지는지 확인 | 가설: 방문자는 관광지와 맛집·시장을 별도로 검색하며, 두 경험을 하나의 코스로 인식하지 않는다.<br><br>“시장을 어떻게 알게 되었는가?”, “관광지와 함께 계획했는가?” 확인 |
| 예스파크 | 이천의 대표적인 도자·공예 경험을 찾는 방문객 인터뷰 | 가설: 방문 목적은 명확하지만 체험 전후의 카페·식사·산책 등 주변 경험을 연결하기 어렵다.<br><br>“다음 일정은 무엇인가?”, “주변 장소는 어떻게 찾았는가?”, “맞춤 추천이 있다면 사용할 것인가?” 확인 |
