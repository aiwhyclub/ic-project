## ② 지역의 불편함을 해결하는 기능

> 답사에서 본 장면 → 그 사람이 겪은 불편 → 그것을 없애는 기능

| 답사에서 본 장면 | 겪은 불편 | 만들 기능 |
| --- | --- | --- |
| 이천역에서 교통을 기다리며 옛 이천역 터를 그냥 지나침 | 남는 시간을 쓸 곳이 없고 근처 로컬 이야기도 찾기 어렵다 | 대기시간별 10·20·30분 “역 주변 빈틈 코스” |
| 설봉공원에서 더위·휴관으로 다시 동선을 찾는 가족 | 주차·운영 여부를 몰라 걷고 검색하며 체력을 소모한다 | 주차·운영·날씨를 반영한 “설봉권역 대체 동선” |
| 관고시장 비장날·마감, 예스파크 즉흥 체험 예약 불가 | 도착 후 이용 조건을 알아 다음 장소를 다시 검색해야 한다 | 막힌 이유 선택 → 현재 위치 기준 플랜B 3곳 |

## ③ 타겟이 필요로 하거나 선호하는 기능

| 필요 — 없으면 안 쓰는 기능 | 선호 — 있으면 더 쓰는 기능 |
| --- | --- |
| 지금 이용 가능 여부: 휴관·마감·장날·예약 | 포기한 장소 “다음에 가기” 저장 |
| 현재 위치 → 대체 장소 이동시간 | 장소별 주의 조건·추천 시간대 |
| 막힌 이유별 플랜B 3곳 + 이동법 | 15~30분 빈틈 로컬 스토리 카드 |

## ★ 다음 주에 실제로 만들 핵심 기능 1개

“막힌 이유”를 누르면 현재 위치에서 갈 수 있는 플랜B 3곳을 보여주는 카드

### 왜 이 기능인가

예스파크의 즉흥 체험, 설봉공원의 휴관·진입 동선, 관고시장의 비장날·마감처럼 현장에서 계획이 끊기는 변수가 반복됐다. 한 화면의 대체 선택지로 바로 검증할 수 있다.
